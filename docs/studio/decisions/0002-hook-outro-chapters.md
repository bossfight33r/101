# ADR 0002 — Хук и аутро как служебные сцены, поле `chapter`

**Контекст.** `Script.hook` должен звучать в первые 10 секунд, `outro` — в конце. Главы YouTube
нужно строить из сцен, но у сцен терминала/кода нет естественного заголовка.

**Решение.**
- При рендере хук и аутро превращаются в служебные `SlideScene` с id `hook` и `outro`
  (заголовок = `title` видео / «Что дальше»). Эти id зарезервированы в сценарии.
- Валидация: хук ≤ 10 секунд по `words_per_minute` канала.
- В `SceneBase` добавлено необязательное поле `chapter: str | None`. Сцена с `chapter` начинает главу,
  без него — продолжает предыдущую. Хук входит в первую главу (00:00).

**Последствия.** Формат сценария чуть шире ТЗ (одно поле), описан в `script-format.md`.
