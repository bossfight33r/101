# ADR 0005 — Этапы, кеш и resume

**Этапы.** `voicing` (TTS → loudnorm → ASR-тайминги) → `rendering` (визуалы) → `assembling`
(сегменты, длинное видео, шортсы, метаданные, миниатюры, превью) → `final_review`.

**Кеш.** Манифест на сцену (`scenes/{id}/manifest.json`) и на видео (`videos/{id}/manifest.json`).
Свежесть = совпали `stage_version`, хеш входов и sha256 всех выходов. Входы визуала включают сцену,
целевую длительность, рендерер+версию, стиль, энкодер и содержимое ассетов (картинка, файлы replay).
Изменилась озвучка → изменилась длительность → перерендер визуала этой сцены, остальные из кеша.

**Resume.** Ошибка → `failed` + `FailureInfo(stage, error_type, message, retryable)`. `studio retry`
повторяет прогон: готовые этапы — из кеша (озвучка и визуалы не переделываются).
Перерендер сцены на ревью сбрасывает только её `visual:*`, `segment:*`, `card:*`.

**Решения ради скорости.**
- 9:16 рендерится только для сцен-кандидатов в шортсы (шортсы делаются только из них).
- Подгонка визуала под длительность (freeze `tpad` / обрезка `-t`) — внутри кодирования сегмента,
  без отдельного перекодирования.
- Очередь — inline (ADR 0001).

**Дополнение: параллельный рендер.** Визуалы сцен рендерятся в `TS_RENDER_WORKERS` потоков (по
умолчанию 2): сцена целиком (обе ориентации) — в одном потоке, потому что у сцены общий манифест.
Озвучка остаётся последовательной (TTS и ASR-модель — тяжёлые и не обязаны быть потокобезопасными).
Шрифты Pillow кешируются на поток (FreeType не потокобезопасен). Строки concat-списков ffmpeg
экранируют кавычки в путях.
