# ADR 0006 — Ревью в боте и публикация

**Бот.** ClipFactory-бота в этом репо нет (ADR 0001) — бот TechStudio свой (`studio bot`), aiogram 3,
только `TS_ADMIN_IDS` (фильтр роутера, чужим — тишина). Логика гейтов — `bot/logic.py` без Telegram
(тестируется напрямую), `bot/handlers.py` — тонкий адаптер. Долгие операции (генерация, рендер,
публикация) — `job`, выполняются в потоке, результат приходит отдельным сообщением.
callback_data ≤ 64 байт: сцены адресуются индексом, `video_id` ≤ 36 символов.

**Гейт 1:** текст сценария со флагами REPLAY/NETWORK и командами, `script.yaml` файлом, кнопки
Approve (только если валидация зелёная) / Прислать правку (YAML-документ, video_id берётся из файла) /
Перегенерировать сцену N.
**Гейт 2:** сжатое превью (360p), шортсы, 3 миниатюры, предупреждения (fallback, fake, главы),
выбор миниатюры обязателен до Approve; Reject → `rejected`; перерендер сцены.

**Публикация.** Только из `final_review` с `final_approved`. Длинное: private + publishAt, описание =
текст LLM + главы (если валидны) + `description_footer`, теги, SRT через captions API, миниатюра через
thumbnails API, при ошибке — `data/studio/exports/{id}/thumbnail.jpg` + заметка. Шортсы — после
длинного с `shorts_interval_hours`, ссылка на полное видео в описании. Дневные лимиты считаются по
локальной дате канала (failed не считается). Публикация идемпотентна — повтор догружает недостающее.
`scheduled → published` — по наступлению publishAt (`studio track`).

**Дополнение.**
- Рендер и публикация видео — под файловой блокировкой `videos/{id}/.render.lock` (`fcntl`): двойной
  клик в боте или CLI параллельно с ботом не запустят второй рендер и не загрузят видео дважды
  (`BusyError`, статус не трогается).
- `studio notify ID` и флаг `--notify` у `script new` / `render` — гейт текущего статуса уходит админам
  в бот, даже если работа шла из CLI. Ошибка уведомления команду не роняет.
- После Reject сценарий можно править (import/YAML в бот) — `rejected` входит в редактируемые статусы.
- На карточке хука шортса субтитров нет: её текст и так крупно на экране.
