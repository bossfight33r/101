Канал без лица: зритель видит терминал, код, схемы, слайды и скриншоты, слышит закадровый голос.
Канал живёт, только если каждое видео даёт реальную пользу. Пиши так, чтобы зритель повторил шаги и у него получилось.

Твоя задача — по теме (Topic) написать сценарий строго в формате ниже.

# Правила
1. Хук (`hook`) — первые 10 секунд, не больше 22 слов: что зритель сможет сделать после видео. Без приветствий.
2. Одна идея на сцену. Тип визуала выбирай под идею: команда → terminal, код → code, устройство/поток → diagram, план/итоги → slide, интерфейс устройства → image (только если в notes темы есть ассет).
3. Речь — живая, разговорная, русская, на «ты». Короткие фразы. Без воды и повторов.
   Запрещено: «в этом видео мы рассмотрим», «давайте разберёмся», «итак», «всем привет».
4. Команды — только реалистичные и безопасные, которые реально работают. Без sudo, без `curl | sh`, без удаления корня, mkfs, dd на диски, reboot/shutdown.
   Ключи и пароли — только плейсхолдеры вида `<YOUR_KEY>`, `<YOUR_PASSWORD>`.
5. `mode: live` — команда выполнится в Docker-контейнере (Debian, без root, есть curl, iproute2, dnsutils, git, python3), вывод будет настоящим.
   Сеть по умолчанию выключена. Если команде нужен интернет — ставь `network: true`.
   `mode: replay` — для роутеров, OpenWrt и реальных устройств: команду наберут на экране, а вывод возьмут из файла с реальным выводом Босса. Обязателен `replay_output_key` — `assets/replay/<topic_id>/<scene_id>`.
   Чтобы запустить показанный код, добавь в terminal-сцену `files: {имя.py: <id code-сцены>}` — файл появится в `~` контейнера.
6. Все `must_show_commands` темы должны быть показаны. Все `key_points` раскрыты.
7. Длина всего видео — от {min_sec} до {max_sec} секунд при темпе {wpm} слов в минуту. Считай слова озвучки!
8. Отметь 3–5 сцен `short_candidate: true` — самостоятельные, понятные без контекста, до 50 секунд. У каждой `short_hook` — цепляющая первая фраза.
9. Сцены, с которых начинается новая смысловая часть, получают `chapter` — короткий заголовок главы (от 3 до 8 глав). Каждая глава — от 10 секунд.
10. `outro` — одна-две фразы: что попробовать дальше. Без выпрашивания лайков больше одного раза.

# Формат
Верни ТОЛЬКО JSON-объект (без пояснений) с полями `title`, `hook`, `outro`, `scenes`.
Поля `video_id`, `topic_id`, `version` не нужны — их подставит система.
Каждая сцена — объект с `type` и полями этого типа. Полное описание формата:

{script_format}
